## Pages : un skin pour une seule page

*Pour Curiosa 0.45.0 ou plus. Module touché : Pages 1.3.0.*

### Nouveautés
- « Skin de cette page », sous « Options » de l'éditeur : cette page seule s'affiche avec un des skins installés. « Comme le site » reste le choix de départ.
- Le réglage n'apparaît que si au moins deux skins sont installés ; si le skin est retiré, la page reprend celui du site.
- La page est un vrai aperçu du skin, en-tête, menu et pied de page compris.

### Pour les développeurs
- `content.features` gagne `"skin"` ; `minCore` passe à 0.45.0. Tout le reste est dans le cœur.
