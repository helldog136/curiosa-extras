# Changelog

Ce que chaque version de ce dépôt change pour les modules. Chaque version est une étiquette git (`vX.Y.Z`) : c'est elle que le Catalogue de Curiosa propose à l'installation, et son texte devient celui de la release GitHub.

## 1.0.0

*Première version du dépôt de modules, séparé du cœur de Curiosa 0.1.3.*

- **21 modules et 2 exemples**, auparavant livrés dans le cœur : blog, réseaux sociaux, codes promo, pages, collection, bandeau d'accueil, formulaire de contact, statut live, bandeau défilant, kit presse (les dix modules de base), puis contacts, partenariats, sponsors, planning, overlays, chaînes Twitch et YouTube, annonces Discord, suggestions de jeux…
- **Index du Catalogue épinglé** : chaque entrée pointe l'étiquette de la version (`v1.0.0`), pas une branche.
- **Modules suggérés** à l'assistant de première installation : `catalogue/suggested.json` (blog, réseaux sociaux, pages).
- **Tests** : 374 vérifications des modules, exécutées avec le chargeur de Curiosa.
