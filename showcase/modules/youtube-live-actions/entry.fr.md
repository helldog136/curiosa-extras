## Ce que ça fait

Quand quelqu'un soutient votre direct YouTube, avec un Super Chat ou un abonnement, une action se déclenche chez vous.

- Écrivez des règles qui relient un don à une action.
- Lisez le chat pendant votre direct.
- Laissez vos modérateurs tout arrêter depuis le chat.
- Affichez les dons dans l'overlay d'alertes.
- Simulez un don pour tester une règle.

## Pourquoi vous allez l'aimer

- Le soutien de votre public a un effet visible.
- Vous pouvez tout couper d'un coup.

## Bon à savoir

- Un journal garde le nom YouTube, le montant et le résultat, pour votre équipe seule (50 lignes au plus).
- Le texte d'un message n'est jamais écrit sur disque.
- Votre assistant IA peut lire l'état et le journal, et simuler une action.
- Ce qu'il ajoute à votre site : un accès pour votre assistant IA.
