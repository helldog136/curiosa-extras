## Ce que ça fait

Une bannière en bas d'écran pour OBS. De temps en temps, elle montre un sponsor, avec son code promo et un code QR.

- Ajoutez l'overlay comme source navigateur dans OBS.
- Choisissez les secondes entre deux apparitions et les secondes à l'écran.
- Montrez ou masquez le code QR.
- Choisissez l'apparence et la couleur d'accent.

## Pourquoi vous allez l'aimer

- Les sponsors sont vus sans longue publicité.
- Le code QR mène directement à l'offre.
