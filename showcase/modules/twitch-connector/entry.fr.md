## Ce que ça fait

Relie votre site à Twitch une seule fois, pour tout ce qui touche Twitch. Un assistant guidé prend environ cinq minutes.

- Suivez l'installation guidée, avec un bouton Copier pour chaque valeur.
- Remplissez les deux champs de votre application Twitch.
- Laissez tous les modules Twitch utiliser la même connexion.

## Pourquoi vous allez l'aimer

- Vous vous connectez une fois, pas une fois par module.
- Les autres modules Twitch fonctionnent ensuite tout seuls.

- [Bot Twitch](entry:twitch-bot)
- [Raid Twitch](entry:twitch-raid)

## Bon à savoir

- Le secret de votre application Twitch reste sur votre propre site.
