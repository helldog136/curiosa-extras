## Ce que ça fait

Garde l'accès YouTube de votre site à un seul endroit. Il lit les chiffres de votre chaîne et le chat de votre direct.

- Enregistrez une seule fois votre accès YouTube.
- Remplissez les informations Google de votre compte.
- Fixez le quota quotidien que votre site peut utiliser.
- Laissez votre site répondre dans le chat de votre direct, si vous le souhaitez.

## Pourquoi vous allez l'aimer

- Tous les modules YouTube partagent une seule connexion.
- Vous restez dans une limite quotidienne que vous choisissez.
