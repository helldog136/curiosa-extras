## Ce que ça fait

Trouve la jaquette de vos jeux vidéo, même quand une source est en panne : RAWG d'abord, puis Steam, puis Twitch.

- Trouvez les jaquettes sans aucun code à saisir.
- Corrigez une mauvaise jaquette en quelques clics.
- Gardez une copie de chaque jaquette sur votre propre site.
- Choisissez quand une jaquette gardée est renouvelée.

## Pourquoi vous allez l'aimer

- Votre planning et vos listes sont beaux sans effort.
- Les visiteurs ne contactent jamais eux-mêmes RAWG, Twitch ni Steam.

## Bon à savoir

- Un code d'accès RAWG gratuit est facultatif.
- Le titre du jeu est envoyé à RAWG, à Steam et à Twitch pour trouver la jaquette.
- Votre assistant IA peut lister les jaquettes à vérifier et choisir le bon jeu.
- Ce qu'il ajoute à votre site : un accès pour votre assistant IA.
