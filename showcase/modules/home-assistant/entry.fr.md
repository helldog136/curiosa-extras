## Ce que ça fait

Relie vos points de chaîne à votre maison : lumières, message lu à voix haute, actions que vous nommez. Un grand bouton « Tout couper » arrête tout.

- Associez votre Home Assistant à votre site.
- Laissez une récompense allumer une lumière ou lire un message à voix haute.
- Refusez les numéros et les mots indésirables dans les messages lus.
- Fixez la longueur maximale d'un message et l'attente entre deux messages.
- Envoyez un test à votre maison depuis l'administration.

## Pourquoi vous allez l'aimer

- Votre public peut agir sur votre pièce, dans les limites que vous fixez.
- Vous pouvez tout arrêter d'un coup.

## Bon à savoir

- Un journal montre le pseudo, l'action et le résultat, pour votre équipe seule (100 lignes, 7 jours).
- Un message refusé n'est pas gardé, seulement la raison.
- Ce qu'il ajoute à votre site : un accès pour votre assistant IA.
