## Ce que ça fait

Ajoute un formulaire de contact sous une page de votre choix. Chaque message devient un contact à relire dans votre carnet d'adresses.

- Choisissez la page qui montre le formulaire.
- Recevez chaque message dans votre carnet d'adresses.
- Recevez un e-mail à chaque nouveau message, si vous le souhaitez.

## Pourquoi vous allez l'aimer

- Les visiteurs vous écrivent sans voir votre adresse e-mail.
- Les messages ne se perdent pas dans une boîte de réception.

## Bon à savoir

- Nécessite : [Contacts](entry:contacts).
- Le nom, l'adresse e-mail et le message sont gardés dans le carnet d'adresses privé de votre équipe, uniquement pour répondre.
- Ils ne sont ni publiés ni transmis.
- Ce qu'il ajoute à votre site : de petits ajouts dans vos pages ; des blocs pour votre accueil ; des notifications par e-mail.
