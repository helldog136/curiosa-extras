## Ce que ça fait

Une source navigateur transparente pour OBS. Elle fait défiler des cartes de votre site : codes promo, articles, annonces.

- Ajoutez l'overlay comme source navigateur dans OBS.
- Choisissez combien de secondes chaque carte reste.
- Choisissez la couleur du texte, celle des cartes et la position.

## Pourquoi vous allez l'aimer

- Le contenu de votre site travaille pour vous pendant le direct.
- Le fond est transparent : il se fond dans votre scène.
