## Ce que ça fait

Laissez votre public suggérer à quoi jouer. Une liste publique montre chaque jeu avec son statut : proposé, prévu, joué.

- Proposez un formulaire de suggestion aux visiteurs.
- Laissez voter pour rejouer à un jeu.
- Ajoutez des jeux vous-même, un par un ou en liste.
- Trouvez les jaquettes automatiquement.
- Affichez les jeux les plus suggérés dans OBS.

## Pourquoi vous allez l'aimer

- Votre public se sent associé à vos choix.
- Vous voyez d'un coup d'œil ce que les gens veulent.
- Un jeu suggéré peut devenir un stream prévu.

## Bon à savoir

- Une suggestion montre sur la page publique le nom du jeu, un pseudo s'il est donné et une note.
- Un petit cookie retient les votes d'un visiteur pendant le mois.
- Votre assistant IA peut lister les suggestions, ajouter des jeux et changer leur statut.
- Ce qu'il ajoute à votre site : sa propre page ; un accès pour votre assistant IA ; des jaquettes de jeux venues de RAWG.
