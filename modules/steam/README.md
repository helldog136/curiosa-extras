# Steam — module communautaire de Curiosa

Affiche le bouton de votre Steam (icône et lien) dans l'en-tête du site. Il fournit le sujet `social.link` au cœur, qui rassemble les boutons de tous vos réseaux : il ne consomme rien et ne stocke rien.

- **Réglage** : l'adresse de votre profil. Collez le lien de votre page. Par exemple : https://steamcommunity.com/id/monpseudo. Le nom seul, l'adresse sans https:// ou sans www. et les adresses courtes sont reconnus ; les paramètres de suivi sont retirés.
- **Plusieurs comptes** : ajoutez une instance par compte (la vôtre, celle d'une personne amie…).
- Seule une adresse https du bon site est acceptée ; rien n'est affiché tant que le profil n'est pas réglé.
