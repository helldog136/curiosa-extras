# Statut live Twitch

Affiche votre lecteur Twitch sur l'accueil et une bannière quand vous êtes en direct.

Le lecteur Twitch affiche, hors ligne, un grand panneau blanc « hors ligne ». Avec le client id et le secret Twitch, le lecteur n'apparaît donc **qu'en direct** (réglage « Quand afficher le lecteur » : « Seulement en direct » par défaut, ou « Toujours »). Sans identifiants, on ne peut pas savoir si vous êtes en direct : le lecteur reste affiché comme avant.
