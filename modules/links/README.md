# Link list / Liste de liens

**EN:** A list of links with icons: your sites, your projects, your favourite pages. Add one list per purpose if you have several. Social networks have their own modules.

**FR :** Une liste de liens avec icônes : vos sites, vos projets, vos pages préférées. Ajoutez une liste par usage si vous en avez plusieurs. Les réseaux sociaux ont leurs propres modules.

Core module of Curiosa (Curiosa License 1.0). Turn it on from the admin, under **Features**; it has no settings, you write the links on its own page.
Module de base de Curiosa (Curiosa License 1.0). Il s'active depuis l'admin, dans **Fonctionnalités** ; il n'a pas de réglages, vous écrivez les liens sur sa page.

## Where it is in the admin / Où le trouver dans l'admin

**EN:** Since 1.1.0 the module declares `adminMenu: "Contenu"` (and keeps `menuGroup: "content"` for an older core): its list appears in the **Content** section of the sidebar, next to Blog and Pages. Before, a list of links that open elsewhere was filed under "Only in Extensions" by the core's default rule, in no menu. The choice of the person still wins: "Only in Extensions" and "Pin to the menu" on the instance page change it.

**FR :** Depuis la 1.1.0, le module déclare `adminMenu: "Contenu"` (et garde `menuGroup: "content"` pour un Curiosa plus ancien) : sa liste apparaît dans la rubrique **Contenu** du menu, à côté de Blog et Pages. Avant, une liste de liens qui s'ouvrent ailleurs était rangée « Seulement dans Extensions » par la règle par défaut du cœur, donc dans aucun menu. Le choix de la personne l'emporte toujours : « Seulement dans Extensions » et « Épingler au menu » sur la page de l'instance le changent.

## Previews of the module page / Visuels de la fiche

**EN:** The module page shows screenshots of what it adds to your site (invented data, no real data).
**FR :** La fiche du module montre des captures de ce qu'il ajoute à votre site (données inventées, aucune donnée réelle).
