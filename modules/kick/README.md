# Kick — module communautaire de Curiosa

Affiche le bouton de votre Kick (icône et lien) dans l'en-tête du site. Il fournit le sujet `social.link` au cœur, qui rassemble les boutons de tous vos réseaux : il ne consomme rien et ne stocke rien.

- **Réglage** : Le nom de votre chaîne Kick ou son adresse.
- **Plusieurs comptes** : ajoutez une instance par compte (la vôtre, celle d'un ami…).
- Seule une adresse https du bon site est acceptée ; rien n'est affiché tant que le profil n'est pas réglé.
