# Sponsors — module communautaire de Curiosa

Affiche vos sponsors et leurs codes promo sur le site. Un module **à contenu** : l'éditeur multilingue, les pages
publiques (`/sponsors`, `/sponsors/<sponsor>`), le sitemap et les liens courts `/go/sponsors/<sponsor>` viennent du cœur.

Ce que ce module ajoute :

- **La mention de partenariat**, affichée au-dessus de la liste et de chaque page de sponsor (réglable, une par langue).
  La réglementation sur la publicité d'influence l'exige : elle ne peut pas être oubliée.
- **Un champ « Partenaire »** : une référence vers une fiche du module *Partenariats* (liste déroulante). Rien de ce
  lien n'apparaît sur le site public.
- **Le sujet `sponsor.card`** (nom, texte, lien, code, logo, date) qui alimente les overlays — l'overlay *Overlay
  sponsors* le digère, sans que ce module le connaisse. Le logo vient de l'image du sponsor, à défaut du logo du partenaire.
- Actions MCP éditoriales générées par le cœur : un assistant peut proposer des **brouillons** de sponsors, jamais les publier.

Plusieurs instances possibles (une liste de sponsors par chaîne, par exemple).
